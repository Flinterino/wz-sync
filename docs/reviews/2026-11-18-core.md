## Verification boundaries

Windows junction cases execute locally. Symbolic-link cases execute on Linux CI; Windows without symlink privilege cannot execute those test bodies. Case-collision fixtures require a case-sensitive filesystem. The alternate-name test exercises its assertions when the volume creates a Windows short name. These platform conditions are distinct from whole-suite pass counts.

Repeated path validation rejects observed reparse points, unsafe casing and traversal. Path and content checks happen before subsequent filesystem operations. A hostile local process can race those operations by changing directory entries or staged bytes. Run with the game closed and keep the profile unchanged during a sync. The recovery tests cover process interruptions with surviving filesystem state. Power-loss recovery has not been verified.

Checksums establish byte integrity relative to the chosen manifest. A sidecar is not publisher authentication, and this stage does not add a signed manifest/release trust policy.

Not verified here: WPF/native accessibility, CurseForge discovery/handoff, actual public mod availability, application signing/releases, game import/join or an actual-profile sync. Those are later stages. Manual rows remain manual requirements, not an automatic-ready claim.
